About This Project

Women Cricket Data Analysis

Women Cricket Data Analysis is a data analysis project created to study Women's Cricket statistics. The project focuses on player performance, match data, runs, wickets and other important cricket statistics.

Cricket data can be stored in CSV format and analyzed using programming and data analysis tools. This project can later be extended with charts, performance comparisons and real match data.
